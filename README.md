# CEP Feedback Portal

A two-page website where people can submit feedback about community events and view all submitted feedback.

## Features
- Feedback form with validation (digits-only phone, unique email, rating from 1 to 5)
- Display page that lists all submitted feedback
- Data is saved in the browser, and new entries are added without overwriting old ones

## Built With
- React + Vite
- Formik and Yup (form handling and validation)
- CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
